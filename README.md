# Data Science Portfolio — Yufeng Zhang

The source of my data science portfolio, published with GitHub Pages:

**https://yufengsam.github.io/data-science-portfolio/**

## Contents

- `index.md` — the portfolio page (name, introduction, skills, project showcase)
- `assets/` — figures used on the page
- `_config.yml` — GitHub Pages theme configuration

## Featured project

[Income, CO₂ and the last three decades](https://github.com/yufengsam/data-science-project) —
a reproducible analysis of the relationship between national income and carbon
emissions per person, 1990–2023. **Status: completed.**

## Publishing

The site is built from the `main` branch, repository root folder, using the
Cayman theme. To preview locally with Jekyll:

```bash
bundle exec jekyll serve
```
